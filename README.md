# Shruti Sarak Portfolio Website

Responsive portfolio built with HTML, CSS and JavaScript.

## Open locally
Open `index.html` in a browser.

## Add your photo
Put your photo in the `assets` folder and name it `shruti-photo.jpg`. The website currently shows a placeholder until your photo is added.

## Add your real details
- Replace `your-email@example.com` with your email in `index.html`.
- Replace generic GitHub and LinkedIn links with your profile links.
- Add your resume PDF as `assets/Shruti_Sarak_Resume.pdf`.
- Confirm internship company names, roles and durations before publishing.

## Certificates
Use `certificates.html` to access the certificate section. Put your PDFs inside the `certificates` folder and make filenames match the links in that page (or update the links).
